# Contributing

Leafellow is at the product/feasibility stage. Small proposals, reader accessibility findings and review of the brand/roadmap are welcome. Discuss substantial implementation before starting it; the mobile framework and first provider route are not settled.

Run `python3 -m unittest discover -s tests -v` and `git diff --check` before submitting. Do not commit credentials, provider session data, private books, learner histories or personal design transcripts. Use synthetic/public-domain/appropriately licensed examples with provenance.

Code and non-brand documentation contributions are submitted under Apache-2.0. Brand changes require discussion and agreement on separate brand rights before contribution; do not assume the code license applies to brand art. Follow existing brand-use terms when discussing the authentic project. Do not promise transfer of rights you do not have.

PR approval, merge authorization, deployments and paid provider usage are separate decisions. No automated release or deployment is configured.
